How it works

  1. Create a room for one person (X). You get a QR code and a link.
  2. Share it: X scans the QR, or you send the link on WhatsApp. X has to be on the same Wi-Fi, hotspot or Bluetooth network.
  3. Unlock: X types their name (and the PIN). Anyone else (Y, Z) gets blocked, and 3 wrong tries destroy the room.
  4. Chat & send files straight between your devices. Everything is end-to-end encrypted.
  5. Burn: when either of you leaves or presses End, the room and everything in it is erased.

Connect without internet

CipherDrop never needs the internet. The two devices only need a local link to each other. Pick whichever you have:

Same Wi-Fi fastest

Both devices on the same router. Files move at full Wi-Fi speed (often 10–60 MB/s).

Hotspot no router, no data

Turn on Mobile Hotspot on this PC (Settings → Network → Mobile hotspot) or on a phone, and connect the other device to it. Mobile data isn't used. Then pick the Hotspot adapter when you create the room.

Bluetooth no Wi-Fi at all

Pair the phone with this PC, then turn on Bluetooth tethering on the phone (Hotspot & tethering → Bluetooth tethering). On Windows, open Bluetooth devices → (phone) → Join a Personal Area Network → Connect using → Access point. A Bluetooth PAN adapter shows up below. Choose it and scan the QR. It's slower (about 0.1–0.3 MB/s), so it suits chat and small files.

Why not direct browser Bluetooth? Browsers can only connect to Bluetooth gadgets; they can't advertise to each other the way the native BitChat app does. Bluetooth tethering gives both devices a real network link instead, and that works in any browser.
